Existing counter-UAV systems address only parts of this decision problem, and none of these approaches extends directly to the full problem. Rule-based and optimization-driven methods allocate jamming resources according to predefined threat priorities [hao2024]. Such priorities must be specified before deployment, yet threat severity is not directly measurable: it emerges from the interplay of distance, velocity, heading, RF activity, and temporal behaviors such as loitering or deceleration during an approach. Moreover, solving the allocation from the current snapshot alone ignores how each target's threat will evolve in the subsequent time slots. Learning-based methods can extract such patterns from data, but they typically optimize individual actions, such as communication-link selection or transmit-power control [rao2022]. Extending a single policy to select K jamming targets among Nt UAVs yields a joint action space of C(Nt, K) combinations, whose size grows combinatorially with Nt. Multi-agent reinforcement learning (MARL) can coordinate multiple decisions [valianti2024, wang2025], but existing approaches generally assume a fixed number of UAVs and encode their states and actions using fixed-dimensional representations. Across these approaches, two fundamental limitations remain: (1) Time-varying UAV populations … (2) Limited scalability … （其後未改動）

修改後

To address this challenge, we formulate counter-UAV jamming as a restless multi-armed bandit (RMAB) problem, which naturally matches its structure: each UAV is an arm whose state keeps evolving whether or not it is jammed, jamming a UAV corresponds to activating its arm, and limited jamming resources allow at most K arms to be activated per time slot. Although optimal RMAB control is PSPACE-hard [papadimitriou1999], the Whittle relaxation [whittle1988] decouples the problem into per-UAV subproblems, each summarized by a scalar Whittle index that quantifies the long-term benefit of jamming that UAV now. Jamming the K UAVs with the highest indices replaces a search over all joint actions with per-UAV evaluation and sorting, and this index policy is asymptotically optimal under suitable conditions [weber1990]. Because each index depends only on its own UAV, the same policy applies regardless of how many UAVs are present. We propose WhittleFormer, a scalable neural index policy that learns these indices directly from interaction data without requiring a known transition model. Its Transformer-based encoder … （其後未改動）

用詞上的取捨：
  • 降低複雜度的是 Whittle relaxation（拆解成逐架子問題），不是「建模成 RMAB」本身；PSPACE-hard 指的是一般 RMAB 的最優解。
  • 「asymptotically optimal」依賴 indexability，目前寫成 “under suitable conditions”；依 Part 2 的 2.3，indexability 可在訓練設定下證明。
  • Whittle index ≠ threat：index 衡量「現在 jam 它多換到的長期效益」，threat 只是當下危險程度。這個區別正好回答 R2-W1「為何用 Whittle index 當 priority」。

2.2 Reward 的正確描述：三個不同層次的量

釐清過程中最容易混淆的一點是：preference 標註看的是過去的軌跡，reward 卻是未來的威脅。這兩者並不衝突，因為它們是三個不同的量：

量看的是什麼什麼時候拿得到
rφ(𝓗it)過去：最近 D 個 frame 的視窗表現出多少威脅；由專家比較過去的軌跡片段學得每一步都拿得到
Git = Σℓ=0H−1 γℓ rφ(𝓗it+ℓ)未來：把同一個 rφ 沿時間往後套在之後每一步的視窗上，再加總只有事後才拿得到：模擬時整條軌跡已確定（hindsight），與 RL 的 Monte Carlo return 同理
WhittleFormer 的 index λθ(𝓗it)只看過去，預測 G部署時使用
r(s, a) = a · Git　　（選中：得到未來威脅 G；不選：0）

論文目前寫錯的地方：4-C-RM.tex:19 寫 “rφ(𝓗t) provides the reward r used in the subsidized Q-learning”，意思是 reward 為當下的 rφ，與實作（G）不符，也沒有 action。這是 reviewer 混淆的主要來源。

2.3 由此推出的性質：index 就是「預測的未來威脅」

訓練時 jam 不會改變 UAV，下一個狀態與 action 無關，因此兩個 Q 值的未來項相同、會互相抵消：

Qλ(s, 1) = E[G | 𝓗] + γ E[V(s′)]
Qλ(s, 0) = λ + γ E[V(s′)]
⇒ Whittle index λ*(s) = E[G | 𝓗]

這帶來幾個好處：

  • Indexability 可以直接證明：「寧可不 jam」的狀態集合是 {s : E[G | 𝓗] ≤ λ}，隨 λ 單調擴大。可用來回應 R2-W3，不必只靠實驗驗證。
  • 先前擔心的「等威脅變大再打」誘因不存在，因為訓練時 jam 不會讓 UAV 消失。
  • 先前擔心的「補貼依狀態而定、與 Whittle 定義不一致」也不構成問題，未來項抵消後固定點仍是 λ* = E[G | 𝓗]。
  • Intro 第三段 “quantifies the long-term benefit of jamming that UAV now” 仍正確，不必改。

2.5 想和老師討論的兩個問題

①既然 index = E[G | 𝓗]，為什麼需要 Q-learning 與 Whittle 框架？

依 2.3，訓練環境下 WhittleFormer 等價於「從過去的軌跡預測未來威脅」，reviewer 可能會問為什麼不直接用監督式學習迴歸 G。可能的回應方向：

  • Whittle 框架提供 Top-K 決策的理論依據（index policy 的漸近最優性、indexability 可證），並能延伸到 jam 會改變 UAV 的環境。
  • 在 R2-F12 的 ablation 中直接比較「監督式迴歸 G」與 WhittleFormer，以實驗回答。

②Q 值中未來被計算兩次

一般 RL 的 reward 是「當下」拿到的，γQ 負責把未來加進來。這裡的 reward G 本身已是未來 H 步的折扣總和，若 γQ > 0，Q 值等於在「未來的總和」上再加一次未來，同一段威脅被重複計算。

Q(s, 1) = G + γQ E[V(s′)]　　Q(s, 0) = λ + γQ E[V(s′)]
  • 對結果（排序）沒有影響：訓練時 s′ 與 a 無關，γQ 那一項在 Q1 − Q0 中抵消，index 不論 γQ 為何都收斂到 E[G | 𝓗]。
  • 對寫法有影響：reviewer 讀到「reward 已是 discounted future threat」又看到 Q-learning 有 discount，可能問「為什麼折扣兩次、Q 值代表什麼」。
    • γQ = 0：Q(s,1) = G、Q(s,0) = λ，直接說 index 就是預測的 G，最乾淨。
    • γQ > 0：補一句「action 不影響轉移，兩個 action 的未來項相同而抵消，index 不受 γQ 影響」。
  • 實務上：γQ > 0 不改變學習目標，但 bootstrap 項 max Q(s′,·) 的估計誤差會讓訓練多一些雜訊。
